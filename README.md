# First Principles

A mastery-based learning app for children that develops foundational reasoning, mathematics, geometry, algebra, physics, and CogAT-relevant skills through short tactile games rather than worksheets.

## Core experience

- 2–4 minute micro-lessons
- See and manipulate a concept before it is explained
- Tactile game mechanics instead of conventional multiple choice
- Immediate visual feedback after mistakes
- Universal read-aloud for learner-facing text
- Child-selected themes and adaptive presentation
- Child feedback controls: too easy, harder, too challenging, more fun, show another way
- Mastery, persistence, transfer, and conceptual connections earn the strongest rewards
- A buildable city/world acts as visible evidence of accumulated learning

## Current prototype

The starter MVP includes:

- five presentation themes
- tactile 3/4 challenge
- read-aloud using browser speech synthesis
- mastery and coin rewards
- transfer bonus
- child-controlled tutor feedback
- responsive/mobile layout
- PWA manifest starter

## Run locally

1. Install Node.js 20+
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL shown by Vite

## Build

Run `npm run build`.
